# Quasi-perfect Sequence-Form Games (QSFGames)

This is the implementation of a game-theoretic planning framework for autonomous driving based on a quasi-perfect equilibrium approach. The implementation has the following main ingredients:

- Lemke’s algorithm
- Dubins path optimization
- Stanley controller
